# Калькулятор нарезки (стабильная версия)

Автономное одностраничное веб-приложение расчёта нарезки рулонных материалов.
Полностью самодостаточно: HTML/CSS/JS в одном файле, без сборки и зависимостей.

## Состав
- `index.html` — приложение (встроенные стили и логика).
- `sw.js` — service worker (офлайн-кэш, `narezka-v3`).
- `apple-touch-icon.png` — иконка.

Все пути относительные — работает по любому адресу GitHub Pages без настройки base.

## Публикация (GitHub Pages)
Settings → Pages → Build and deployment → Source: **Deploy from a branch** →
Branch: **main** / **/ (root)**. Сборка не требуется.
